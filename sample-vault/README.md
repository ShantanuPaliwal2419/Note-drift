# NoteDrift Fictional Sample Vault

This sample vault contains notes about a fictional software library called **libfoo**.
It is designed to let you test all NoteDrift features completely offline using recorded fixtures.

## Getting Started in 2 Minutes

1. In Obsidian, select **Open folder as vault** and choose this directory (`sample-vault`).
2. When prompted, select **Trust author and enable plugins**.
3. Open `notes/libfoo-overview.md`.
4. Click the **activity icon** in the left ribbon or run command **NoteDrift: Scan current note**.
5. NoteDrift will display the side review panel showing:
   - `[!] LIKELY OUTDATED` for `libfoo 1.5` (official documentation lists 2.0).
   - Evidence card with official release notes link and diff.
   - Safe apply preview: click `[Apply...]` to preview the callout before it is inserted.
6. Run **NoteDrift: Check links in current note** to test dead-link rescue on `https://old.libfoo.dev/guide`.
